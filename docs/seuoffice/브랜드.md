# SeuOffice 로고

![SeuOffice 앱 아이콘](../../apps/shell/build/icons/128x128.png)

SeuOffice 로고는 호박색과 보라색 종이 위에 남색 문서 한 장을 세운 모양이다. 남색 문서의 오른쪽 위 모서리는 연보라색으로 접혀 있고, 가운데에는 흰 네 갈래 별이 있다.

## 앱 아이콘과 로고 원본

- [앱 아이콘](../../apps/shell/build/brand/app-icon.svg)은 기본 크기의 원본이다.
- [작은 앱 아이콘](../../apps/shell/build/brand/app-icon-small.svg)은 32px 이하에서 쓴다.
- [가로형 로고](../../apps/shell/build/brand/logo-lockup.svg)는 로고와 제품 이름을 나란히 놓을 때 쓴다.

원본을 수정한 뒤 저장소 루트에서 `node tools/gen-brand-assets.mjs`를 실행하면 앱과 설치본 아이콘, 사이드바 로고, 웹 파비콘, 저장소 공유 이미지가 갱신된다. 웹 런처의 `apps/web/public/favicon.png`는 32px 앱 아이콘과 같은 파일이다. AI 단추의 말풍선과 파일 종류별 그림은 제품 로고가 아니다.

## README와 GitHub 공유 이미지

한국어와 영어 README는 앱 아이콘 원본을 직접 표시한다. GitHub에서 저장소 링크를 공유할 때는 [공유 이미지](../../.github/social-preview.png)(1280 × 640px)를 쓴다. 저장소에 파일을 올리는 것만으로는 링크 미리보기가 바뀌지 않는다. 저장소 관리자가 **Settings → General → Social preview**에서 이 PNG를 업로드해야 한다.
