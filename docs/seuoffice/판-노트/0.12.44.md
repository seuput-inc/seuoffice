- 다른 서비스 안에 붙여 쓰는 화면에서 자동 저장은 붙인 쪽이 켤 때만 동작합니다. 저장할 때마다 사람이 저장했는지, 자동 저장인지, 붙인 쪽이 요청했는지도 함께 알려 줍니다.
- 다른 서비스 안에 붙여 쓰는 화면은 문서 내용과 파일 이름을 브라우저 저장소에 남기지 않습니다.
- Mac에서 워드 문서를 연 채로 앱을 끝내거나 '다시 시작하고 설치'를 누르면 앱이 끝나지 않던 문제를 고쳤습니다.
- Mac에서 이전 판을 쓰는 중에 워드 문서를 연 채 '다시 시작하고 설치'를 누르면 앱이 멈춘 듯 보일 수 있습니다. 그럴 때 앱을 한 번 더 종료하면 새 판으로 바뀌고, 문서와 설정은 그대로입니다.
