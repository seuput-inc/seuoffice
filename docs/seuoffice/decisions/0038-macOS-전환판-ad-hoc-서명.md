# 0038 macOS 전환판은 ad hoc으로 서명한다

- 날짜: 2026-11-21
- 상태: 확정. macOS 전환판에 대해 [0035](0035-macOS-서명-정체-고정.md)를 대신한다.

## 결정

Apple Silicon용 중간 Electron과 대상 Tauri 앱은 ad hoc으로 서명한다. 인증서를 만들거나 `.p12`를 공급하지 않는다. 인증서 지문을 입력하거나 서명 키를 키체인으로 가져오지도 않는다. 키체인에 저장된 사용자의 AI 키를 읽는 일은 빌드 서명과 별개다.

고정 인증서를 쓰면 판이 바뀌어도 키체인이 같은 앱으로 인식할 수 있지만, 모든 빌드에 개인 키가 필요하다. 전환판은 그 키를 배포하지 않는 쪽을 택한다. 앱의 코드 해시가 달라지므로 업데이트 때 키체인이나 macOS 권한 대화상자가 다시 뜰 수 있다.

## 무엇을 검증하는가

ad hoc 서명은 서명 뒤 코드가 달라졌는지 검사할 수 있게 한다. 누구나 다시 서명할 수 있으므로 같은 번들 ID와 유효한 서명만으로 배포자를 확인할 수 없다. Developer ID 서명도 Apple 공증도 아니다. 원본 저장소의 승인된 빌드 실행과 커밋, 산출물 출처 증명(attestation), 설치 파일의 크기와 해시를 별도로 대조한다. 확인한 바이트만 채널에 승격한다. Windows의 무서명 정책과 [두 채널의 저장소 선택](0037-Tauri-배포-저장소.md)은 바뀌지 않는다.

## 설치 시험의 한계

출처 증명은 설치 성공이나 자료 보존을 증명하지 않는다. 일반·안정 채널 모두 실제 설치된 구판에서 중간판, 첫 Tauri, 다음 Tauri로 이어지는 G6 시험을 아직 통과하지 않았다. [넘어가기 시험](../3단계-넘어가기-시험.md)에서 원본 앱과 합성 자료로 각 교체를 확인하기 전에는 발행하지 않는다. Gatekeeper나 격리를 끄는 방식으로 실패를 통과시키지 않는다.

교체와 복귀를 실행하는 것은 출발 판이다. 이미 배포한 구판에서 중간판으로 가는 첫 교체에는 새 복귀 처리가 없다. 중간판 이후에도 새 번들을 열라는 요청이 거부됐을 때만 이전 번들을 다시 연다. 실행을 시작한 뒤의 충돌이나 사용자 자료 복원까지 보장하지 않으므로 설치 시험 전에 앱과 시험 자료를 백업한다.
