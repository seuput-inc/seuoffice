# Frozen protocol properties

Status: source only; no SANY/TLC/native execution or counterexample reproduction has run. These requirements are fixed before the model source, not adjusted to obtain a passing run.

1. **AtomicReplace:** publishing a new attachment and logically invalidating the captured old document occur in one admitted transition. There is no state with the new attachment published and the old document still active. Source: Main's terminal-transition contract; `RendererGeneration::with_active_all_retiring` and `AdmittedDocumentRetirement::retire`.
2. **NoStaleEffects:** a worker holding only the old document's gate cannot commit an old-document effect after replacement. Source: the reported old-document-only worker gap; `RendererGeneration::with_active` checks active under the same gate.
3. **ObserverOutsideGates:** retirement observers are notified only after the retiring operation releases every captured native/assets/generation/Slides/Docs/PDF/cancel gate. An observer may reenter those gates. Source: `native_owner/effects.rs::DeferredDocumentRetirements` placement and Drop.
4. **NoAliasDoubleAcquire:** canonical gate acquisition acquires any shared source/destination identity once. Source: `with_live_all`, `with_active_all`, and pair helper alias deduplication.
5. **NotificationConservation:** for **every captured retired document**, exactly its deferred notification is delivered once after release, even when the transition unwinds. One document's delivered wakeup cannot compensate for another's loss. An unwind before retirement invents no notification. Source: `DocumentRetirementPlan`/`DeferredDocumentRetirements` RAII and unwind regression source. The initial aggregate boolean abstraction was insufficient for this frozen requirement; it was replaced before any execution with document-indexed queued/delivered sets and counts, including a second-document-only loss mutant.
6. **EventuallyTerminal:** with weak fairness for the finite acyclic protocol's enabled next step, workers, one external loss action, and the queued observer finish. A synchronous notify while retaining gates or a repeated acquisition of an alias must have a nonterminating witness. This is a model scheduling property, not a claim that real OS/UI callbacks are fair or terminate.

`TypeOK` is model hygiene. The frozen protocol definitions are banner-delimited in the TLA module. Mutation witness configurations select specific properties to expose a stale effect or deadlock topology; the passing configurations retain the complete frozen property set. No state constraint or symmetry reduction is used.
