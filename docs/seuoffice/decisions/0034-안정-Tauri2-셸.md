# 0034 첫 Rust 앱은 안정 Tauri 2와 시스템 웹뷰로 낸다

- 날짜: 2026-11-16
- 상태: 선택 확정, 구현과 필수 검증 진행 중
- 결정한 사람: 스풋. 안정 Tauri 2 방향을 승인했고, 전체관리 세션이 두 프로젝트에 같은 결정을 전달했다.
- 대신하는 것: 결정 0029의 CEF 선택과 결정 0026 3항의 "시스템 웹뷰가 다르면 CEF"라는 선택 규칙. React 공유와 기존 기능·자료 이행 검증은 그대로다.

## 맥락

사용자는 실제로 교체할 수 있는 Rust 앱을 먼저 내고, 남은 Node 기능은 그 뒤 Rust로 순차 이식하기로 했다. CEF를 위한 큰 빌드 자원을 Rust 앱 자체의 요구처럼 다루지 않으며, 유료 패치 CEF 생산을 첫 교체의 선행 조건으로 삼지 않는다.

현재 CEF 후보는 Tauri 3 알파와 별도 네이티브 권한 변경에 기대고 있다. 그 변경과 일치하는 실행물은 아직 확보하지 못했고, 통합 후보도 실제 앱의 필수 관문을 통과하지 않았다. 안정 Tauri 2와 OS 웹뷰로 방향을 바꾼다.

과거 시스템 웹뷰 시험이 성공했다는 뜻은 아니다. 결정 0029의 Mac WKWebView 시험은 편집기 52쪽이 51쪽으로, PDF 43쪽이 45쪽으로 달랐다. 그 원문과 실패를 보존하고 현재 편집기에서 원인을 좁혀 고친다. 정적 검사나 합성 진단을 실제 앱 성공으로 올리지 않는다.

## 결정

1. **껍데기는 안정 Tauri 2다.** `tauri` 2.12.5, `tauri-build` 2.7.4로 시작한다. CLI는 독립된 판인 2.12.4다. macOS는 WKWebView, Windows는 WebView2를 쓴다. 3.0.0-alpha.6과 CEF는 출시 경로에서 제거한다. 잠금 파일은 정식 호스티드 준비에서 생성하고 실제 `--locked` 검사로 확인한다.
2. **지금의 React 화면과 실제 문서 엔진·Node 기능을 유지한다.** GPUI·Iced·Slint로 화면 전체를 다시 쓰거나, 기능 없는 Rust 창만 먼저 내지 않는다. 첫 판의 Node 공존과 순수 네이티브 전환 완료를 구분한다.
3. **네이티브 권한을 실제 플랫폼 경계로 이행한다.** 원래 뷰·문서 세대·발신 권한, 취소, 늦은 콜백 거부와 정확한 응답 대상을 보존한다. URL·라벨·렌더러가 보낸 식별자로 네이티브 증거를 대신하지 않는다. stock IPC의 403을 풀거나 일반 저장·정리 권한으로 우회하지 않는다.
4. **닫힘과 프로세스 종료는 다른 결과다.** OS 뷰를 닫았다는 사실로 원래 렌더러 프로세스의 실제 종료 영수증을 만들지 않는다. CEF 전용 생산자와 새 플랫폼 생산자의 차이는 호출자까지 함께 이행하고, 기존 동결 속성의 적용 범위를 다시 확인한다. 옛 모델이나 부분 성공을 새 플랫폼의 증명으로 쓰지 않는다.
5. **첫 교체의 필수 관문 뒤 바로 출시한다.** 지원 형식의 실제 열기·편집·저장·다시 열기·종료, 인쇄·PDF, 같은 출시 후보의 실제 UI, Mac·Windows 꾸리기, 기존 앱 정체·자료·저장된 인증정보, 앱 안 업데이트와 실패 시 복귀를 확인한다. 형식이나 기능을 몰래 빼지 않는다. 이 관문이 통과하면 잔여 전체 Rust 전환이나 고급 NSS 완료를 기다리지 않는다.
6. **실제 사용자 설치와 자료는 시험 대상이 아니다.** 허용된 일회용 호스티드 환경과 합성 자료를 쓴다. 접근성·보안 설정을 바꾸거나 새 출시용 디버그 권한을 열어 관문을 대신하지 않는다. 원소스·기존 실패·WIP·라이선스 고지는 보존한다.

버전 근거는 [Tauri 2.12.5 릴리스](https://github.com/tauri-apps/tauri/releases/tag/tauri-v2.12.5)와 [CLI 2.12.4 레지스트리 원문](https://registry.npmjs.org/@tauri-apps/cli/2.12.4)이다. 라이브러리와 CLI의 판 번호가 같다고 가정하지 않는다.

## 버린 대안

- **Tauri 3 알파와 패치 CEF를 먼저 완성한다.** 현재 실행물 공급과 별도 엔진 빌드를 첫 앱의 선행 조건으로 두므로 선택하지 않는다.
- **화면까지 Rust 도구로 다시 만든다.** 공유 React 편집기와 문서 기능을 유지하는 첫 교체보다 범위가 크다.
- **Node 제거를 모두 마친 뒤 첫 판을 낸다.** 사용자가 정한 첫 앱 우선·이후 순차 전환과 반대다.
- **문서 차이·권한 차이를 무시하고 먼저 띄운다.** 저장 결과와 기존 사용자 자료를 보존하는 교체가 아니므로 허용하지 않는다.

## 결과

시스템 웹뷰로 Chromium 생산을 제거하는 방향은 확정됐다. 문서 배치, 네이티브 IPC·수명, 인쇄·PDF, 설치·자료 이행의 실제 검증은 아직 완료되지 않았다. 코드 이행과 호스티드 검증 결과를 분리해 기록하며, 부분 성공만으로 기존 Electron 설치본을 덮어쓰거나 릴리즈하지 않는다.
